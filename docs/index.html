MEET THE 0.6 CONSOLE

Keep the bench moving.
Keep each target straight.

A console for each adapter, with its own connection, video source and run. Give each one a name you recognise and switch when you need it.

01 / SWITCH

More machines.
One place to work.

Add a console tab, connect its adapter and choose its capture card. Your assignments are remembered. Runs stay with their console while you look elsewhere.

Release captured input before switching: Ctrl + Alt + Esc (Option on a Mac).

02 / UNDERSTAND

Know what the
board is doing.

Read the running firmware version, target USB state and link status in the console. Open Adapter for protocol, held-input counters and the age of the last status reply.

A verified flash and a running board are separate checks. The app tells you which one you have.

03 / RECOVER

Fix the pairing.
Stay in the app.

On Windows and Linux, use Repair pairing to forget and pair the selected adapter again. A brief BOOT press authorises it. Even a remembered adapter that won’t connect has a recovery path.

macOS still requires System Settings for the forget step. Console and recovery guide →

THE TWO PATHS

Bluetooth does the typing.
HDMI brings the picture.

One ESP32-S3 adapter per target. Add a USB HDMI capture card for each live picture you want. The target needs no Bluetooth, network connection or installed agent for basic control.

FIRST ADAPTER? START HERE.

From parts
to a picture.

A supported dual-port ESP32-S3 board is about $10. Budget separately for the capture card and cables.

Open the full setup guide →

  1. Install on your computer

    Choose Windows, Linux or macOS below. The firmware comes with the app; you don’t need a development toolchain.

  2. Flash over COM

    Connect only COM to your computer. Open Adapter → Flash adapter, choose the port, then wait for verification. The 0.6 dialog shows the firmware, progress and retry options.

  3. Connect, pair, choose video

    Unplug COM. Connect the native USB port to the target, and its HDMI output through the capture card to your computer. Press BOOT briefly, pair in kvm-it, then choose the card under Video.

A FEW GOOD QUESTIONS

Before you
plug it in.

For the precise limits, start with the platform matrix and security model.

Is this an IP-KVM?

It is a desktop KVM for nearby machines. The controller reaches the adapter over Bluetooth LE; the target’s picture comes through an HDMI capture card. It does not provide control over the internet.

How many adapters can I use?

0.6 adds separate console tabs and prevents two live consoles from claiming the same adapter or capture card. We haven’t established a simultaneous-adapter limit. Your Bluetooth controller, USB bandwidth and capture devices matter.

Windows pairing repair and GUI use with multiple physical adapters are maintainer-confirmed. Exact counts and failure-case input handoffs weren’t reported. See the evidence table.

Can I use it without a capture card?

Yes, for control: the adapter still presents a USB keyboard and mouse to the target. Without a capture card there is no live picture, and screen-aware workflows need video.

What if pairing or flashing fails?

In 0.6, open Adapter → Repair pairing on Windows or Linux. Press BOOT briefly when asked. macOS requires forgetting the device in System Settings. For flashing, use COM, keep native USB off the controller computer, and follow the dialog’s retry or BOOT recovery steps. Follow the guide.

What happens to passwords and held keys?

Secret fields are masked and their contents aren’t logged or saved. Release captured input with Ctrl+Alt+Esc (Ctrl+Option+Esc on a Mac). Disconnect and keepalive expiry are designed to release held input; evidence and remaining hardware checks are documented in the security model.

Can it boot a machine from the network?

The adapter has an optional read-only iPXE boot drive, off by default. It is UEFI-only. Secure Boot support depends on the target trusting Microsoft’s third-party UEFI CA; this path has VM coverage, not a real-PC verification pass. Read the boot-drive limits.
