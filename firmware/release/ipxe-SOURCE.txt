ipxe.img carries the iPXE UEFI binary (EFI/BOOT/BOOTX64.EFI), built from UNMODIFIED upstream iPXE source by scripts/build-ipxe.sh
in the kvm-it repository (default configuration, x86-64 UEFI target; the build is repeatable with the pinned container image).
Upstream source: https://github.com/ipxe/ipxe at commit 6262f1081fe185564e8ec8365a1d23597ec6e6f5.
An archive of exactly that source, ipxe-6262f1081fe1-source.tar.gz (with a .sha256), is attached to every kvm-it release that ships this file.
